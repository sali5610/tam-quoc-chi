## Navigation model
- Global: Trang chủ / Sử truyện / Nhân vật / Atlas / Tàng thư. Search remains header entry (on Reader retain existing contextual controls); no sixth tab. Reader belongs to Sử truyện. Mục lục is shared hierarchy, Trong tập is scene list, Địa điểm jumps to local map, Atlas opens global map.
- Home: preserve existing hero art and primary resume/start; show current chapter compact preview (max three episode rows and open full chapter link), era overview and existing Wiki/Atlas shortcuts; never duplicate full library.
- Library: single published era card, future eras collapsed when available; show active/resume era, arc and chapter path initially, other branches collapsed; independent explicit open/close, preserve expansion and scroll on returning; show year span, count, numbered title and current episode. No misleading read completion inferred from a single resume bookmark. No empty future content. Use responsive list, not card nesting. On large chapters use progressive reveal (e.g. 12 rows then Xem thêm; direct link/current item always reachable); on desktop can use two-pane index/list using existing styles, not mandatory new interaction.
- Display terms: Thời đại / Hồi / Chương / Tập; Hồi is proposed Vietnamese label for Arc, not schema rename. Keep 8 chapters and all existing IDs; don't reorganize solely by production batch. Arc coverage computed from min/max episode spans, labeled published coverage not era end. Narrative order follows manifest; chronology follows event registry. EP12 and EP18 have overlapping earlier years, never reorder story.
- Reader: short chapter context above title, existing scene TOC and settings; previous/next includes titles and crosses chapters, no spoilers beyond published title. Retain exact prior bookmark/position storage and existing keys. Global library opens last active branch or current reading branch; shared TOC returns focus and traps focus when modal.
- Navigation state: preserve original #/read/ep-ID, #/library, #/people, #/atlas/YEAR, #/collection and #/search. Optional validated query within hash for chapter/event, do not break existing links. Save per-route scroll and selected filters/expanded IDs in session state; use browser back/forward to restore; only new destinations scroll top, restore reader after content and assets settle using scene anchor/offset plus old pixel fallback. No overwrite last reader when browsing Atlas/Wiki; explicit origin episode/scene tracked; direct Atlas entry shows related episodes, not fake return. Separate permanent bookmarks from transient route state.

## Atlas
- One canonical time state (year, optional map-layer month, optional event ID). Derive sorted distinct event years and counts from registry, no duplicated fixed lists. Default last Atlas selection or reader anchor on explicit transition, otherwise first supported story anchor. Retain legacy year routes incl 168. Year picker + previous/next mốc (not +/- one calendar year) with noninteractive compact density chart; select/search grouped by historical era for long list. Counts label events not battles. Optional month selector only for supported dataset year; map date is independent evidence precision, not an asserted event date. Unknown date stays year/range, no synthetic January for historical claim. 168 no territory layer; do not fabricate 169–179 or unsupported boundary snapshots. Default year list only published story event years; broader dataset exploration not default, retain existing capability behind clearly labeled optional mode if needed (no false story coverage). All controls bind to canonical state; don't remount Leaflet on every year; update layer, inspector, URL and graph atomically. Back/forward and deep event link restore; same-year event pins/list/relations linked by stable event ID. If event unresolved show list and precision warning; never invent coordinates. Keep journeys off by default, layer controls separate from chronology, map pan/zoom not reset unless explicit focus action or new route requires it. Event list ordered by sourced chronology with stable tie-break and uncertainty disclosure, not episode number; 196 has 11 events; allow year group and event selection; relations same selected event, legacy graphs preserved. Compact episode atlas scopes to episode events incl multiple years; preserve existing map evidence and captions.
- Mobile order: compact time header, map, inspector segmented Sự kiện/Nhân vật/Quan hệ, expandable layers; iPad landscape/desktop side inspector, map legibility. 44px controls, chart noninteractive so no tiny targets, keyboard and screen-reader year/count status. No horizontal page scroll, avoid visual congestion. Playback, if retained, follows canonical supported timeline and explicit stop/reduced-motion rules.

## Wiki/Search/Tàng thư
- Wiki starts search + contextual discovery; show bounded first page (e.g. 24) and total, load more deterministic, no invented importance ranking; filter published era/arc/chapter/episode, sourced faction only with explicit date context; maintain name/Hán tự/title accent-insensitive search, gallery, canonical profiles, quote/radar/backlinks. Distinguish no matches from no data.
- Search grouped by episode/person/place/event using existing index and registries; stable IDs, no fabricated aliases, grouped counts, bounded previews and see all; links preserve context; excerpt must not reveal beyond selected published scope. Empty query guidance, no match recovery; keyboard accessible.
- Tàng thư group marks by episode then chapter in manifest order; retain multiple marks and exact stored offsets, deletion and resume. No new storage migration that loses data.
