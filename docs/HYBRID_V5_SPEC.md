## 2. Visual language
One cohesive visual direction, not options: an illustrated historical book meets a strategy game dossier. Editorial hierarchy > decoration. Warm paper ground, cool ink contrast, restrained cinnabar accent; gold only thin separators/selection detail. Use existing verified art; do not colorize, stretch, obscure text or imply a literary plate is a documentary image. Never use fake painting or decorative AI art.
Proposed tokens (verify contrast in rendered implementation):
paper #F7F2E8; raised paper #FFFCF5; ink #242B2A; deep ink #233B38; muted #635E54; line #D8CEBD; seal #9A342C; restrained brass #82643D; map existing faction palette remains unchanged. Decorative gold never body text. White space replaces card borders. Flat surfaces, no fake torn-paper/shadow stacks, no gradients obscuring text; only functional modal elevation.
Typography: existing Georgia/serif stack for narrative (Georgia, Times New Roman, serif, verify Vietnamese glyphs; no new font dependency); system-ui sans for controls, numbers and metadata. One hero display 36–42px mobile, 48–60 tablet/desktop, 1.12–1.2; headings 25–30px; body 19px mobile / 20px tablet, 1.75–1.85 line height, existing A-/A+ 17–25; captions 13px, controls 14px. Reader line length ~55–70 chars max, 16–24px phone side margins, 24–40 tablet. Spacing 4/8/12/16/24/32/48/64; controls >=44px target. One page title; Hán tự as small motif or name, not repeated labels everywhere.
Motion: 160–240ms sheet/menu transition, 250–400ms gentle art reveal or section divider; only when context changes. No scroll-jacking, parallax on prose, forced reveal of essential facts, audio autoplay or perpetual effects. Reduced motion disables nonessential transforms; content never waits for animation.

## 3. Screen specifications (phone first)
### Home & library — opening scroll
Top compact header with brand and search, no always-open tree on home. Hero one verified context-safe art (reuse EP01 Eastern Han context plate, not novel scene presented as historical; caption available) or ink typography if unsuitable crop. Visible first-screen title, short invitation, single primary 'Đọc tiếp' (or 'Bắt đầu đọc' before any session). Resume shows actual episode title and stored position; no fabricated percentage. Secondary entries Nhân vật and Sa bàn below hero. One chronological list grouped by actual era/arc, titles and years only; no second duplicate tree. Library retains hierarchical navigation using one collapsed/expandable structure with selected episode. Desktop uses broad editorial hero (text/art split), two-column episode list if reading order remains clear. Phone one column; tablet portrait two-column home where enough space, landscape editorial layout. Preserve routes and search.
### Reader — illustrated chronicle
Compact top line: back/mục lục, episode number, reading progress; full story title + date once. Start narrative promptly (no scene carousel or settings block above first paragraph). On phone use one unobtrusive reading bar with contents, font/settings and bookmark, hide duplicate global navigation while reader controls provide return/library and atlas. Never hide navigation behind scroll-only gestures. On wide screens content 620–720px centered, context rail only when space permits (>=1100px suggested); 834 portrait single column, 1194 landscape optional rail. Scene navigation + people in one disclosure/sheet; tap name in prose opens shared profile, closing restores focus/position. Keep story prose and satire naturally readable, collapse optional modern/variant text with meaningful topic labels, maintain concise attribution; remove demo-style 'Vén màn sử liệu' and standalone reveal blocks only after factual content is available directly in narrative, adapt tests to verify actual behavior rather than feature-proof widgets. Sources one end disclosure, no EVD/registry/checklist in default UI. Preserve useful historical uncertainty, chapter chronology and episode navigation. 
Scene art: use existing placement semantics (heading exact anchor / literary blockquote anchor), art visible outside optional disclosure; if several plates share anchor show one ordered vertical pair/stack, not hidden carousel. Width 100% of reading column, preserve intrinsic dimensions and aspect, no crop in reader; title + brief nature label (e.g. 'Tranh Diễn nghĩa') and source disclosure. Missing art simply no slot; no placeholder. Art must not vanish when satire disabled. Avoid layout shift, lazy load below fold. Map at end as concise contextual section with link; retain embedded controls and relation disclosure, no duplicate heading. End with next/previous episode links and source disclosure. 
### Wiki — hồ sơ nhân vật
Search and episode filter in one compact row, collapsible on phone if needed. Portrait-led 2-column phone grid (narrow fallback one), 3–4 tablet, 4–5 desktop; no ornate card border around every item. Name + role visible, Hán tự secondary. Same image registry; if no art, one typographic seal only, no repeated 'chưa xác minh' label. Shared PersonSheet: full-height accessible sheet on phone, 640–800px dialog on wide screens, sticky close and header; no forced float. Portrait uncropped in detail, small nameplate, concise biography then 6-axis radar with one timeline control (button/selector presentation unified, accessible native fallback), visible six values and * low-confidence note; quote cards as typographic quotations with literary attribution and optional context; related episodes as links, sources compact disclosure. No extra axes, changes to scores, fake attributes or spoilers. Gallery existing zoom, keyboard and focus preserved.
### Atlas — map is primary
Full viewport-width map workspace with compact title/year control. On phone prioritize 45–60dvh map with controls in one toggle/disclosure and event detail below/map sheet without blocking markers; no auto-open. At >=1100px use 2/3 map + 1/3 inspector; 834 portrait stacked. Timeline anchor and month are distinct labels ('Mốc truyện', 'Tháng') and actual selected year is visible. Retain timeline playback, city/road/people toggles, journey selector default off, zoom, faction/rank rings, label suppression, region/unresolved distinctions, legend, source/CC BY-SA attribution; keep existing Leaflet and dataset. Relation graph optional panel, not a competing heading. Event details show event title, people, place and narrative link first; provenance in disclosure; no internal IDs. Preserve dashed paths as event links not routes, no new coordinates. Preserve map pan/zoom and actual route to story position.
