Use existing Motion and Rough Notation; diagrams must remain legible without motion. At narrow widths stack nodes; no horizontal panning required for basic reading. Existing Atlas only for supported geography; no fabricated routes, formations, coordinates or troop counts.
- Keep prose intact; visual blocks after their anchored narrative beat, not before a spoiler. Quotes only existing sourced quotations; editorial summaries not styled as verbatim quotes. No forced stamps or images where evidence is absent. No minimum artificial image quota; aim for multiple meaningful visual beats per episode. Use sources panel and descriptive labels rather than visible evidence IDs.

Museum object is contextual, not an actual artifact owned by a named character.
