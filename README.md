# Tam Quốc Chí — Historical Storytelling

Private-first Vietnamese historical storytelling project based on Trần Thọ's 《三國志》. Bùi Tùng Chi's commentary is a distinct source layer.

**Status: Phase 0 (planning only). No website or Vercel deployment.**

Read `docs/PROJECT_CHARTER.md`, `docs/HISTORICAL_RULES.md`, `docs/GOVERNANCE.md`, `docs/DECISION_LOG.md`, and `docs/LATEST_HANDOFF.md` before making changes.

Layers: protected source/provenance → evidence/knowledge → editorial storytelling → UI/art. Every major phase requires PO approval.
